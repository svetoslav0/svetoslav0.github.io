# Доброто започва от мен — уебсайт

Уебсайт на образователната програма **„Доброто започва от мен“** — програма за развитие на силните страни на характера и добродетели при ученици от I до VII клас.

## Технологии

Статичен SPA сайт без бекенд — подходящ за GitHub Pages:

- **HTML** — цялото съдържание е в `index.html` (три страници като секции);
- **CSS** — `css/style.css`, модерен адаптивен дизайн без външни библиотеки;
- **JavaScript** — `js/app.js`, hash-базиран рутер (`#/`, `#/programa`, `#/za-nas`), мобилно меню, анимации при скрол и лайтбокс за галериите;
- **Шрифт** — [Nunito](https://fonts.google.com/specimen/Nunito) от Google Fonts (с кирилица).

## Структура

```
site/
├── index.html          # SPA — начало, „За програмата“, „За нас“
├── css/style.css       # Стилове
├── js/app.js           # Рутер и интерактивност
├── img/
│   ├── banners/        # Корици на тетрадките (I–VII клас)
│   ├── books/          # Страници от тетрадките
│   └── mockups/        # Мокъпи на помагалата
└── info/               # Изходна информация за програмата
```

## Локално стартиране

Не са нужни зависимости — отворете `index.html` в браузър или стартирайте лек локален сървър:

```bash
python -m http.server 8000
```

и отворете <http://localhost:8000>.

## Публикуване в GitHub Pages

1. Качете съдържанието на папката в GitHub хранилище.
2. В **Settings → Pages** изберете клона и главната директория.
3. Сайтът работи изцяло с относителни пътища и hash-навигация, така че не изисква допълнителна конфигурация.

## Страници

- **Начало** (`#/`) — представяне на програмата: какво включва, тетрадките по класове, защо силните страни, за кого е предназначена;
- **За програмата** (`#/programa`) — подробна информация, галерии със страници от тетрадките и мокъпи, обучения (1 квалификационен кредит), контакт;
- **За нас** (`#/za-nas`) — предстои да бъде попълнена.
